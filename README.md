## Принципы будущего сайта

Первый экран должен объяснять клиенту решение его задачи, а не строиться вокруг терминов «внешний production manager» или «аутсорсинг закупочной функции».

Акцент - сам Динар, настоящие фотографии и изделия, личное ведение заказа, понятный процесс и прозрачные условия. Нельзя создавать впечатление собственного завода или несуществующей команды, а также заявлять неподтверждённые отзывы и гарантированную экономию.

План привлечения клиентов: сначала Яндекс Директ, затем SEO. Дизайн нужен выразительный, лёгкий и нешаблонный. Первая версия использует статические HTML/CSS/JavaScript без внешних зависимостей.

## Сайт v03 — изделия, полезные материалы и личный опыт

12 страниц в `public/`: главная; картонные коробки; коробки с ложементом; шоубоксы и SRP; стойки и припаки; опыт Динара; раздел «Полезное об упаковке» и пять статей о конструкции, материалах, тираже, образцах и отделке.

Коммерческие формулировки опираются на исследование проекта и дополнительную проверку Wordstat от 19.09.2026. Работа с юрлицами указана явно. 500 и 1000 коробок — примеры количества для обсуждения, не фиксированный минимум. Белые предметные изображения сгенерированы и обозначены как иллюстрации конструкций, не выполненные заказы.

Требуется установленный Node.js. Из корня проекта:

```sh
npm start
```

Адрес: http://127.0.0.1:4173. Сервер раздаёт только `public/`, без исследования и приватных файлов. При занятом порте: `node scripts/serve.mjs 4188`.

Тексты продуктов и статей — `scripts/content.mjs`, общие тексты и шаблоны — `scripts/build.mjs`. После изменений: `npm run build`. Стили и поведение — `public/assets/`. Проверка синтаксиса: `npm run check`.

Сайт работает без JavaScript; JavaScript добавляет мобильное меню, компактное оглавление на телефоне и деликатное появление блоков. Ситуации клиента и оглавление раскрываются нативно; анимация учитывает reduced motion. Заявки не отправляются через сервер: используются прямые контакты.

Основной адрес: https://dinar.moscow/. GitHub Actions публикует только public/. Прежний адрес https://terrifickook.github.io/dinar-moscow/ перенаправляется на собственный домен после его подключения. Локальный сервер закрыт от индексации заголовком X-Robots-Tag. Исследование остаётся локальным. Список нужных фотографий: SHOT_LIST.md.
