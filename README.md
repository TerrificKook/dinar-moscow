# dinar-moscow

Рабочий проект для исследования спроса и последующей разработки личного сайта `dinar.moscow`.

## Контекст

- Владелец проекта: Динар Динмухаметов.
- Договоры планируются через ИП; реквизиты пока не предоставлены и не должны предполагаться.
- Это отдельный личный сайт, не редизайн `dinar.agency` и не копия `dinarcraft.ru`.

Предложение проекта: помочь организовать изготовление POSM, упаковки, образцов и тиражей - разобраться в задаче, подобрать подходящее производство, организовать образец и контролировать выполнение заказа.

Опыт со слов владельца:

- более 24 лет в рекламно-производственных проектах;
- четыре года в InnerWorkings: закупки, тендеры, сравнение подрядчиков, отчётность и контроль производства;
- работа с картоном, полиграфией, упаковкой, пластиком, металлом и производственными площадками.

## Принципы будущего сайта

Первый экран должен объяснять клиенту решение его задачи, а не строиться вокруг терминов «внешний production manager» или «аутсорсинг закупочной функции».

Акцент - сам Динар, настоящие фотографии и изделия, личное ведение заказа, понятный процесс и прозрачные условия. Нельзя создавать впечатление собственного завода или несуществующей команды, а также заявлять неподтверждённые отзывы и гарантированную экономию.

План привлечения клиентов: сначала Яндекс Директ, затем SEO. Дизайн нужен выразительный, лёгкий и нешаблонный. Первая версия использует статические HTML/CSS/JavaScript без внешних зависимостей.

## Локальный сайт v01

Четыре страницы в `public/`: главная, коробки с ложементом, шоубоксы и дисплеи, опыт Динара.

Требуется установленный Node.js. Из корня проекта:

```sh
npm start
```

Адрес: http://127.0.0.1:4173. Сервер раздаёт только `public/`, без исследования и приватных файлов. При занятом порте: `node scripts/serve.mjs 4188`.

После изменения текстов/шаблона в `scripts/build.mjs`: `npm run build`. Стили и поведение — `public/assets/`. Проверка синтаксиса: `npm run check`.

Сайт работает без JavaScript; JavaScript добавляет мобильное меню и разбор коробки по слоям. Заявки не отправляются через сервер: используются прямые контакты.

Версия предназначена для визуальной приёмки. Установлен noindex. Сохранение кода в GitHub не означает публикацию сайта: Pages, DNS и домен не настраивались. Исследование остаётся локальным.
